# Архивный мини-пример RAGDOLL

Этот набор сохранён для сравнения, но больше не является основным корпусом
проекта. Основной датасет находится в `data/raw/multidoc2dial/`.

Используется категория `tablet` из набора RAGDOLL:

- репозиторий: <https://github.com/spfrommer/ragdoll-data-pipeline>
- архив: `dataset/final_dataset.zip`
- исходная папка: `dataset/tablet/`
- лицензия, указанная в карточке датасета: CC BY 4.0

В этот учебный проект перенесены:

- `products.csv` — бренд, модель и URL каждого товара;
- `content_extract/0.txt` ... `7.txt` — очищенный текст восьми товарных страниц.

Число в имени текстового файла соответствует индексу строки в `products.csv`
после заголовка. Например, `0.txt` относится к Alcatel 3T 10.

Некоторые страницы исходного набора извлечены не полностью. Загрузчик явно
помечает документы короче 50 слов, чтобы это ограничение не потерялось.
