# Исследование Prompt Engineering

Эксперимент выполнен на 20 вопросах с моделью `yandexgpt-5-lite`. Для всех вариантов использовались одинаковые найденные фрагменты и temperature `0.1`.

## Сравниваемые варианты

- `plain` — обычный текстовый ответ;
- `json` — требование вернуть JSON без передачи формальной схемы;
- `pydantic` — JSON Schema из Pydantic передаётся внутри prompt;
- `structured_output` — нативный `text.format=json_schema` Yandex Responses API.

## Результаты

| Вариант | Schema, % | Ошибки JSON | Correct, % | Semantic | Citation, % | Confidence MAE | Время, мс |
|---|---:|---:|---:|---:|---:|---:|---:|
| `plain` | — | 0 | 80.0 | 0.765 | 95.0 | — | 2521 |
| `json` | 100.0 | 0 | 70.0 | 0.785 | 95.0 | 0.285 | 2700 |
| `pydantic` | 95.0 | 0 | 75.0 | 0.775 | 90.0 | 0.200 | 2684 |
| `structured_output` | 100.0 | 0 | 75.0 | 0.771 | 95.0 | 0.250 | 2820 |

`Schema` показывает долю ответов, прошедших валидацию `StructuredRAGAnswer`. У варианта
`pydantic` все ответы разобрались как JSON, но один объект не соответствовал схеме, поэтому
schema adherence составил 95%. Обычный prompt не имеет структуры, и эта метрика для него не
применяется.

## Выбранный вариант

В основной pipeline выбран `structured_output`. Он получил итоговую оценку `0.871` с учётом соблюдения схемы, корректности ответа, семантического сходства и валидности ссылок на фрагменты.

Обычный prompt показал 80% по автоматической эвристике корректности, однако не гарантирует
машиночитаемый контракт. `structured_output` выбран как лучший вариант именно для API: Yandex
Responses API принудительно применяет JSON Schema, после чего ответ дополнительно проверяется
Pydantic. В отличие от JSON-prompt, корректность структуры не зависит только от выполнения
текстовой инструкции моделью.

Поле `confidence` нельзя считать откалиброванной вероятностью: Structured Output вернул `1.0` для
всех 20 вопросов, в том числе для неполных ответов. Поле сохранено в контракте для исследования,
но не используется для автоматического принятия решений.

Exact Match рассчитывается, но не используется как единственная оценка: корректная переформулировка ответа обычно не совпадает с эталоном посимвольно.

Полные данные находятся в `data/experiments/rag/`.
